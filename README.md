# Blog

Kategori, içerik, taslak ve mesaj yönetimi olan blog sitesi.

## Ne var

Hakkında, kategori, içerik ve iletişim controller'ları vardır. Katmanlar ayrı projelerdedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework MVC, Entity Framework, Code First ve FluentValidation.
